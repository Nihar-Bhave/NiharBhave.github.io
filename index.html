E-Commerce Delivery Performance Dashboard

2026

An interactive Tableau dashboard that shows how reliably an e-commerce business delivers orders, and which regions fall behind.

Problem
Raw order data doesn't show whether deliveries arrive on time or where delays concentrate. The goal was to turn it into KPIs that support operational decisions.
What I built
A Tableau dashboard using calculated fields, with KPI tiles, a monthly order trend, a chart of the top 10 states by late orders, and a purchase-year filter.
Results
  • Analysed 96,470 orders, with 91.89% delivered on time and 7,820 late.
  • Average delivery duration of 12.56 days.
  • SP had the most late orders (2,386), followed by RJ (1,663).

View on GitHub (opens in a new tab): Predictive Maintenance and IoT Telemetry System

Predictive Maintenance & IoT Telemetry System

2026

A machine learning application that estimates the probability of equipment failure from sensor readings.

Problem
Equipment that fails without warning causes downtime. This project explores how sensor data can flag failure risk before a breakdown.
What I built
An automated pipeline that ingests, cleans and stores vibration, temperature and RPM readings in SQLite, a Random Forest classifier trained with Scikit-learn to predict failure risk, and a Streamlit diagnostic dashboard with failure probability predictions and anomaly alerts.
Results
  • Processed 1,000+ sensor readings, including 88 logged failures (an 8.8% breakdown rate).
  • Failure probability prediction with a Random Forest classifier.
  • Interactive risk simulator where sensor values can be adjusted to see the predicted outcome.
  • Python
  • Google Sheets API
